# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use GitHub private vulnerability reporting from the repository's **Security**
tab. Include the affected component or route, reproduction steps, potential
impact, and any suggested mitigation. Please avoid including secrets or personal
data in the report.

The maintainers will acknowledge a report after it is reviewed and will keep
the reporter informed when a fix or coordinated disclosure is appropriate.

## Supported versions

Nacre UI has not published its first stable package. Security fixes currently
apply to the latest commit on `main`.
